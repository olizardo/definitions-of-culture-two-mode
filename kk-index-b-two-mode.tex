\begin{abstract}
Kroeber and Kluckhohn's classic 1952 monograph \emph{Culture: A Critical Review of Concepts and Definitions} brought together over a hundred scholarly definitions of culture and indexed the key concepts they discuss. We build one network from that index to explore how concepts and definitions are connected. In the \emph{definitions network}, concepts like ``society'' and ``beliefs'' are linked to 171 definition codes, grouped into seven categories and credited to the author or authors that K\&K index under each. Each code is one quotation, identified by its author, year, printed pinpoint and opening words. We present basic statistics about the network, visualize the data using correspondence analysis and spanning trees, and highlight the key concepts and definitions that anchor it. Data-driven types found in the wording of the definitions do not recover K\&K's categories at better than chance.
\end{abstract}

\section{Data and networks}

We build one network from K\&K's Index B. The \emph{definitions network} links 470 concepts---concrete ideas like ``society,'' ``customs,'' and ``beliefs''---to 171 definitions of culture, which K\&K number as codes. Each code is credited to the author or authors K\&K index under it, and falls into one of seven categories, which K\&K label with the capital letters A through G: A Descriptive, B Historical, C Normative, D Psychological, E Structural, F Genetic, and G Incomplete. Of the 171 codes, 169 appear in K\&K's own author index. The other two, C-I-18a and D-II-16, are attributions cited in the main text of the book that the index does not list. Boroch quotes two parts of four K\&K codes separately, lettered (a) and (b): A-3, E-5, F-II-4 and F-II-7. We keep each of these as two codes, A-3(a) and A-3(b) and so on, which is why the eight variant codes replace four. K\&K print one index entry per code, so each variant starts with its parent's concept links. For 29 of the 41 concept links copied in this way, we kept the link only on the variant whose quotation contains the concept's name; the other 12 remain on both variants. That assignment is our reading of the quotation text, not a printed fact. We leave out K\&K's Part III statement codes (C-5, D-5, D-7, E-17), which sit outside the Part II typology. Concepts have consistent names; where a concept appears under different headings in K\&K's source text, we treat it as a single concept. Each code is one quotation, identified by its author, year, printed pinpoint and opening words. Section~\ref{app:construction} describes how each code was matched to its quotation and how the a and b variants were built.

The definitions network naturally breaks into 10 separate components, with the largest containing 626 nodes. Our analysis focuses on this largest component, which contains virtually all the meaningful connections. We use maximum spanning trees across multiple projections to identify the strongest connections in different views of the network.

\section{Maximum spanning trees}

A maximum spanning tree (MST) keeps the strongest ties in a network while still connecting every node, using as few links as possible. A two-mode network has no ties between two concepts or between two definitions, so we analyze it through multiple one-mode projections \citep{everett2013dual-projection-c89}. Following Breiger \citeyearpar{breiger1974}, two concepts are tied if they share at least one definition, with weight equal to the number they share. Likewise, two definitions are tied through the concepts they share. In matrix form, the projections are:
\[
W_{\mathrm{concept}} = A A^{\top}, \qquad W_{\mathrm{def}} = A^{\top} A,
\]
where $(W_{\mathrm{concept}})_{ij} = \sum_k a_{ik} a_{jk}$ counts the definitions that include both concepts $i$ and $j$. Each projection is a weighted graph whose edges are the off-diagonal pairs with positive weight. We build projections from the 2-core of the network's largest component.

The maximum spanning tree of each projection is found by computing the minimum spanning tree on negated weights, $-w$. \citet{kruskal1956} sorts edges from largest weight to smallest and adds each unless it would close a cycle, producing a tree that maximizes $\sum_{e \in T} w_e$. Because the 2-core is connected, each tree has exactly $|V| - 1$ edges. In the visualizations, node size shows betweenness within the tree and node color shows the community structure detected using Newman's leading-eigenvector method applied to the tree.

The definitions network has two main projections. The concept-level tree (Figure~\ref{fig:mst-def-sub}) shows how 160 concepts cluster. The definition-level tree (Figure~\ref{fig:mst-def-code}) shows how 149 definitions cluster. Table~\ref{tab:mst-def-betweenness} lists the top 10 concepts and definitions by betweenness in their maximum spanning trees.

\section{Data-driven types: non-negative matrix factorization}

The spanning trees and the community colors above classify nodes hard: each code belongs to exactly one community of the tree. Non-negative matrix factorization (NMF) \citep{lee2001algorithms} offers a soft, parts-based alternative. It approximates a non-negative matrix $V$ by a product $W H$ with all entries non-negative, so every code carries a loading on each factor and every factor is an additive mixture of the original features, with no subtractive terms. We ask how far data-driven types of the definition wording agree with K\&K's own seven categories A--G. The factorization uses the same base-R implementation throughout (Euclidean multiplicative updates, deterministic given a seed, with ten random restarts per value of $k$), and it fixes $k$ at seven, one factor per K\&K group. Fixing $k$ this way is a choice, not a result: the reconstruction error falls monotonically in $k$ without an elbow, and restart agreement is irregular (mean adjusted Rand index 0.48 to 0.70 over $k = 3$ to $8$), so neither criterion selects a number of factors on its own.

\subsection{Types from the wording of the definitions}

The analysis asks the question of the definition texts themselves, independently of K\&K's coding. The corpus holds 171 definition codes carrying a quotation: the Table~2 texts mapped to K\&K codes through the crosswalk, the appendix-only texts, and one statement K\&K prints itself (a Part II page footnote). Three Table~2 columns that repeat another column's quotation word for word are not counted again. Documents average about thirty-four words (median 28), so the term--document matrix is built restrictively: tokens of three letters or more, a stopword list that removes the words nearly every definition contains (culture, society, social, man, and the general definitional vocabulary total, whole, learned, acquired), and terms kept to a document frequency between two documents and half the corpus, leaving 403 terms weighted by TF--IDF. The four quotations K\&K and Boroch print in French or German enter as English translations (K\&K's own rendering for Maquet, ours for the other three, not yet checked against the printed pages). The factorization is run at $k = 7$, one factor per K\&K group.

The factors again find recognizable themes rather than K\&K's categories (Figure~\ref{fig:nmf-texts-factors}), and we label them by their leading terms: \emph{species-specific ability} (events, species, use, dependent, ability), \emph{order and operation} (order, operation, self, superorganic, complex), \emph{mental and holistic} (concept, mean, holistic, traits, mental), \emph{goals and persons} (certain, rather, others, persons, goals), \emph{symbolic process and adjustment} (concrete, process, symbolic, experience, adjust), \emph{material and transmitted behavior} (material, non, transmitted, socially, institutions), and \emph{passed down generations} (generation, passed, down, everything, common). On a corpus this small a factor can be driven by one author's phrasing, so the labels should be read as descriptive of the top terms, not as clean concepts. The labels for mental and holistic and goals and persons are the least clear, since their leading terms include generic words (rather, certain, some, mean). Against the A--G groups the agreement is close to chance (adjusted Rand index 0.012, against a permutation 95th percentile of 0.016), and no factor has more than 54\% of its codes in one group.

\subsection{Interpretation}

The wording of the definitions does not recover K\&K's taxonomy. Two readings are possible. One is that K\&K's groups classify the emphases of individual \emph{statements}, and that these emphases cannot be recovered from quotations of about thirty words each. The other, which we find more plausible, is that the seven groups are editorial categories---useful for organizing a bibliography---rather than dimensions along which the corpus varies. This is consistent with the spanning-tree picture above, where the vocabulary the Genetic group concerns itself with sits on a peripheral chain of the concept tree rather than forming a region of its own, and with the community structure of the trees, which follows concept vocabulary, not authorial schools. The null result should be read against the method's limits as well: the number of factors was fixed to match the taxonomy under test rather than selected by the data, the short corpus makes TF--IDF factors fragile (restart agreement ranges from 0.48 to 0.70 for $k$ from 3 to 8), and the quotations are the passages Boroch selected, not the authors' full works.

\section{Limitations}

The networks depend on the K\&K Index B transcription and on the verified-code filter. Element names are not unique across headings, so same-named elements are merged, which can join unrelated entries. Several readings depend on OCR corrections recorded in the repository's manual-fix files; the validators check structure and round-trips, not the content of each edge. Two codes that are not in Index A are included: C-I-18a and D-II-16, from the main text. K\&K's Part III statements (C-5, D-5, D-7, E-17) are excluded. The basis for each is documented in the repository. The four split codes and the 29 link decisions that separate their variants (see the data section) are judgments: the variants share one K\&K index entry, and the text-based assignment of concept links is a reading that a reader can check against the quotations, not a printed fact. The definition-level trees and the text factors depend on these decisions.

\section{Constructing the code-level data}\label{app:construction}

The analyses use one object: a table with a row for each of the 171 K\&K definition codes. Each row gives the code's group and subgroup, its sub-elements, and the citation that identifies its quotation. This section records how that table was built, the choices made along the way, and the basis for each. Two sources are joined. K\&K's Index A and Index B, read from a scan of the 1952 monograph, give each code its author, year and sub-elements. Boroch's article \citet{boroch2016} gives each code a quotation with a printed pinpoint. Every join follows a stated rule, and each judgment is recorded with its basis in the project's provenance log.

\subsection{Sources and the unit}

The unit is the code: one printed index entry in K\&K, and one quotation in Boroch. Boroch's appendix has 171 codes. His Table 2 has 135 columns, 132 of which match an appendix code. The two sources number codes differently. Boroch renumbers within each group, so his A10 (Winston 1933) is K\&K's A-9. Codes are therefore matched by author, year, group and subgroup. Positional agreement is kept only as a check: of 100 matches made by name and year, 48 agree with the position.

\subsection{Index A and Index B}

Index A (authors) and Index B (sub-elements) were read from the OCR text layer and corrected by explicit rules. The corrections are recorded in a manual-fix table of 142 rows, each with its printed-page evidence. A further 10 rows recover codes that the OCR glued into element names, and 14 rows record name decisions. The project avoids general character rules, because a rule such as reading a y as a 5 silently produced codes from unrelated tokens. Each manual fix is keyed to a parsed token, and the checks confirm that every key matches one.

The universe is 171 codes. Of these, 169 appear in K\&K's author index. The other two, C-I-18a (Maquet 1949) and D-II-16 (Aberle et al. 1950), are cited in main-text footnotes but not listed in the index; their Index B entries are read from the sub-element entries that carry them. Four Part III statement codes (C-5, D-5, D-7 and E-17) are excluded, since they are K\&K's statements rather than Part II definitions.

\subsection{Matching Boroch's codes to K\&K's}

The crosswalk matches each Table 2 column to a K\&K code. Of the 135 columns, 119 match automatically when exactly one code fits. The remaining 16 are settled by 15 hand decisions, each with a basis, and one recorded slip correction. Three Table 2 columns have no appendix entry of their own: A10a, C1-5a and F4-6. Each is a verbatim copy of another quotation. A10a repeats A10 (Winston 1933), C1-5a repeats C1-5 (Firth 1939), and F4-6 repeats F4-5, which is the entry Boroch's numbering misprints as F4-6. None of the three adds a quotation, so the object does not use them. The F4-5 quotation is Kluckhohn and Kelly 1945a (printed p. 87), and it gives K\&K's F-IV-5. K\&K's printed codes A-10a (Lowie 1937) and C-I-5a (Lynd 1940) take their quotations from the appendix entries A12 and C1-6.

\subsection{Quotations and citation keys}

Each code has one quotation. Boroch supplies 170 of them: the 132 Table 2 codes and the 39 appendix-only codes, less the Sears addendum (C1-22), which is linked to a specialty code rather than to a network code. D-III-4 has no Boroch entry, and its quotation is K\&K's printed footnote 14 (Roberts 1951, pp. 3 and 6, printed p. 60). Four quotations are not in English and are rendered from a translation table: B-17 and C-I-18a from French, and F-I-5 and F-II-3 from German. C-I-18a uses K\&K's own printed English. The other three are working translations that have not been checked on the page images.

Each code is identified by a citation key: Boroch's author, year and printed pinpoint, together with the first six words of the quotation. The key is unique for all 171 codes, with no missing values. The pinpoints are Boroch's as printed and have not been checked against the source works. The key therefore identifies a quotation as Boroch reports it, and the pinpoint is the first thing to check against a source.

\subsection{Splitting the a and b quotations}

Boroch quotes parts of four K\&K codes separately, labeled (a) and (b). K\&K prints one index entry for each of these codes, so the object had one code where Boroch has two quotations. On 2026-10-30 the project split each of the four codes into two variants (Table~\ref{tab:splits}). The split follows Boroch's quotations and is not a distinction K\&K prints. Each variant takes its own quotation and its own citation key.

Because K\&K gives one index entry per code, each variant starts with a copy of its parent's sub-element links, 41 in all. A lexical screen then assigns 29 of the 41 to one variant. A link stays on the variant whose quotation contains the sub-element's name and not on the other. The 12 links where both or neither quotation contains the name remain on both variants. The screen is a word match, so a name used in a generic sense, such as ``total'' or ``past,'' can be assigned wrongly. Each assignment is a reading of the quotation text and should be treated as a judgment. Removing a link also removes the heading edge that carries it, which accounts for 34 edge rows. Together the split takes the verified network from 167 to 171 codes and from 1189 to 1201 edges.

\subsection{Checks and open items}

The build's validators check the network's structure, its round trips and its attributes, but not the content of each edge. The block check places 1301 of the 1326 Index B edge rows (before the 34-row removal) in their printed block, and 25 in another block. The page-image review covers 23 of those 25. Several items remain open. The year of K\&K's footnote 5, which Boroch gives as Linton 1945a, was read from the page image at 150 dpi, and a higher-resolution check is still needed. The three duplicate columns need recorded decisions in the crosswalk, and the text analysis must be brought into line with them. The three non-English translations need checking against the page images. The Boroch pinpoints need checking against the source works. The 29 link assignments are judgments on the text, as described above.
